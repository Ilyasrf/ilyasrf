## About Me

I'm a systems-level developer from Morocco, trained at **1337 School (42 Network)** — one of the most rigorous peer-to-peer programming schools in the world. There, I built a strong foundation in **C/C++**, memory management, networking, and algorithms under extreme time pressure and real-world constraints.

I care about writing software that is **correct, efficient, and maintainable**. I thrive on understanding how things work at the lowest level — from memory allocation to OS internals.

- **Education:** 1337 School — Tétouan, Morocco
- **Focus:** Systems programming, networking, embedded systems, tooling
- **Approach:** Ship it right, not just ship it fast

## 42 School Journey
